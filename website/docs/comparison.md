## Honest tradeoffs

**Where CasaStudente wins**

- The **only** Forlì-specific stack with verified listings, all-inclusive pricing, multilingual UI, digital leases, marketplace payments and roommate matching — in one product.
- Open-source: anything you don’t like, you can fork.
- Open institutional APIs make local journalism and policy work possible.

**Where CasaStudente isn’t the answer (yet)**

- If you want **maximum inventory at any cost**, Immobiliare.it has more raw listings nationally. We trade volume for verification.
- If you want **subsidised housing**, Er.Go is the right answer — but only if you fit the criteria and there’s a bed left (there usually isn’t).
- If you want a **purely social experience**, Facebook groups are unmatched. We add structure on top.

## When each tool fits

| If you’re… | Use… |
| ---------- | ---- |
| A fuorisede student arriving in September | **CasaStudente** for safety, all-inclusive pricing and roommate matching. |
| A low-income student with a scholarship | **Er.Go** first; **CasaStudente** if the waiting list bites. |
| A landlord with empty apartments and time to vet tenants | **CasaStudente** — the rent guarantee removes your biggest fear. |
| A landlord who only wants Italian-speaking professionals | **Immobiliare.it** or **Idealista**. |
| An Erasmus student arriving from abroad | **CasaStudente** (multilingual, virtual tours) or **HousingAnywhere** (more international inventory). |

## Why “open source”

The Italian student-housing crisis isn’t a single-city problem. CasaStudente is built so that the next student city — Cesena, Bologna, Parma, Pavia — can clone the codebase, change the brand, and launch in weeks instead of months. The product wins by being unfair to landlord-side fragmentation, not by being a moat.
